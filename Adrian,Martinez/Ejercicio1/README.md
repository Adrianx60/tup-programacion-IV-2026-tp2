# Ejercicio 1: Gestión de Rectángulos (API REST)

API RESTful desarrollada con **ExpressJS** y **MySQL** para administrar rectángulos, calculando automáticamente su perímetro y superficie en el servidor.

## Tecnologías
* Node.js & Express
* MySQL2
* Express-validator
