# Ejercicio 3: Gestión de Calificaciones de Alumnos (API REST)

API RESTful desarrollada con **ExpressJS** y **MySQL** para administrar las calificaciones de los alumnos en distintas materias, calculando promedios y aplicando restricciones de unicidad mediante clave foránea.

## Tecnologías
* Node.js & Express

* Express-validator
